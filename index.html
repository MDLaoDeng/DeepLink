时间

注意：时间系统只能开一次，开了之后不能关、也不能重设起点（要换时间轴就新建一条对话）。 开启那一刻会把已经聊过的消息和记忆里的日期，按 1:1 往前排到起点之前 —— 比如 10 月 18 日开、设成 9 月 12 日， 10 月 15 日聊的内容就变成 9 月 9 日。真实时间也会留着，搜索时可以选按哪种时间。

时间域关联（把这条线和别人的线接成同一个世界）

关联之后两条线共用一个时间轴：冻结 / 解冻一起，故事里的日期也一致。 前提是两边世界观差不多 —— 差太多会拒绝（由 AI 判断）。 关联会把这条线的时间基准对齐到对方，已经聊过的消息日期按固化值不变。

设好之后，故事时间就按 1:1 跟着现实走。也可以在聊天框里直接写「（第二天）」「（到了约定时间）」把它推过去。 合法时段由角色的出生日期 + 年龄算出来（例：2012-02-10 出生、年龄写 12 → 只能落在 2024-02-10 ~ 2025-02-10 之间）； 这两项缺一个就算不出时段，也就开不了时间系统。开了之后年龄会随故事时间增长，时段跟着往后移。 出生日期填成 0 年 0 月 0 日 是唯一例外：无限年龄，不做时段限制。

性格变化（让他慢慢变成另一个样子）

点「规划路线」让 AI 排一条 4~6 周的变化表，之后按故事时间每过一周走一格（和聊天频率无关）。 不改角色卡，只在提示词里叠一层 —— 点「恢复原样」立刻回去。这里也会消耗一次调用。

别人那儿的事

其他线最近提过他的事，会按他对那个人的信任决定要不要告诉 TA —— 信任够高才主动说起（≥45），一般般就含糊过去。离线剧情生成时会自动跑一次， 这里是可以手动补跑的那次。

换别家平台？可以，但要知道三件事

              
DeepSeek 不是唯一选择。只要对方「兼容 OpenAI 接口」，都能填进来用。但请先知道：

              
    
                
  • 多数比 DeepSeek 贵一些。DeepSeek 的优势就是便宜；换别家通常是为了它的某款特殊模型（比如能看图的、能画图的），聊天本身没必要换。
    • 
                
  • 地址要自己去搜。App 里不内置别家的地址清单（每家会变），请到该平台的官方文档里找「兼容 OpenAI」的接口地址——通常是 https://xxx/v1 这种带版本号的样子。
    • 
                
  • 模型名也要照文档抄，大小写、斜杠、连字符一个都不能错。
    • 
              

              
怎么填多套？「设置 → 主模型」那块点「添加配置」，就能建第二、第三套，最多 6 套；每套都能单独起名（默认叫配置一、配置二…）。每套 = 一个平台的接口地址 + API Key + 它的模型名（模型一栏每行写一个，可以写好几个）。

              
什么时候才需要点「保存设置」？记住这条就不会白填：改卡片里的内容（名字、地址、Key、模型名）要滚到底点「保存设置」才生效；而「添加配置 / 删除 / 用这套」是点了就立刻生效并落盘的，不用再点保存。（顺带一提：点这三个按钮时，你其它区卡片里没保存的改动也会一起被存下来——所以别把不想留的实验内容留在输入框里。）

              
聊天页右上角的模型按钮（对话设置按钮左边）：点它会展开所有配置里的全部模型，分好组、点一下就切过去——接口地址和 API Key 会跟着一起换，不用回设置里手动改。这个按钮只切「主模型」，听觉/朗读/画图/视觉那是另一回事（见第十四节）。

            

            

              
二、开始聊天

              
    
                
  • 底部输入框打字，点右边 ↑ 发送；电脑上回车也能发，Shift+回车换行。
    • 
                
  • 想让它先想清楚：保持「深度思考」开着，右侧可选「思考·低 / 高 / 拉满」。
    • 
                
  • 思考用哪种语言？跟着你走：你这条消息以中文为主，它就被要求全程用中文思考；英文为主时才放开。
    • 
                
  • 回答完不会再把你强行拽到底部：你翻上去看旧消息，它就停在那儿；你本来就贴着底部，它才继续跟。
    • 
                
  • 要最新消息：开「联网搜索」，它会先查再答（可在设置里换搜索源）。
    • 
                
  • 生成中点「停止」可随时中断。
    • 
                
  • 快捷回复：输入框左边、加号右边那个没有边框的气泡按钮（键盘图标那个）。点它会收起键盘、在键盘原来的位置弹出一个面板，AI 站在你的立场给你 4 条「这时可以怎么回」——它读的是角色的设定、你们的记忆，以及你自己的性格设定，所以不会 OOC、前后也接得住。不满意点「换一批」，一次最多 5 批。每句左边有个铅笔：点一下这句就填进输入框、键盘跟着弹回来，你改完再发。面板开着时点输入框，会自动收起面板、唤回键盘。
    • 
                
  • 继续说：角色最后一条消息的操作栏里（和修改、复制、删除同一排）多了个「继续说」按钮，点一下让角色接着往下说（不会重复已说过的，也不会从头开始）。它只在最后一条是角色消息时出现。
    • 
                
  • 故事时间：开了时间系统后，顶栏的「对话设置」按钮上会直接显示故事里的时:分（点它就是下面说的那个浮窗）。也可以直接在聊天框里写「（第二天）」「（到了约定时间）」「（20:30）」把时间推过去 —— 越出角色设定的合法时段会被拒绝并说明。设置见「对话设置 → 时间」。
    • 
                
  • 对话设置：点顶栏那个「💬 ＋ 时间」的按钮，会在它下面弹一张小卡，两栏 —— 上面一栏进对话设置（记忆 / 参数 / 时间 / 日记都在这儿），下面一栏是实时显示的故事时间。
    • 
              

            

            

              
三、发文件 / 图片 / 拍照 / 语音

              
    
                
  • 加号（＋）：拍照和上传文件合并成了一个入口。点输入框左边的「＋」，会在它右上方弹出一张小卡，两项：拍照上传 / 上传文件。
    • 
                
  • 上传文件：文件（txt / md / 代码等）直接读成文字附在消息里；图片走的是「先转文字再喂给模型」——默认由「视觉模型」把图写成一段描述，再把描述发给主模型（因为绝大多数文字模型看不了图）。只有你确认主模型本身能看图、并在设置里勾了「模型兼容」时，原图才会直接发给主模型。见第十四节。
    • 
                
  • 拍照上传：拍照或选图，拍完可裁剪、旋转、画笔、箭头、加文字，再选“附带在消息上”或“直接发送”。
    • 
                
  • 麦克风：语音输入（需在设置里配好「听觉模型」，硅基流动的 FunAudioLLM/SenseVoiceSmall 免费）。
    • 
                
  • 打开「画图」开关后，可让 AI 生成图片（需配好「文生图」模型）。
    • 
                
  • 在「设置 → 文生图」里开「手机里允许角色主动分享图片」，角色在手机里主动找你时就能顺带发图：画风按场景自选（自拍走写实、梗图走二次元、随手画走手绘…）；和角色本人相关的图会存进它的个人图库，下次生成前先比对，长相 / 发型 / 衣着不会前后对不上。想要更稳，再开「用图生图保持角色形象一致」（要平台支持 /images/edits，不支持会自动回落，不影响出图）。

七、角色扮演（重点）

              
    
                
  1. 开法：设置 → 打开「启用角色扮演模式」；侧栏顶部会出现角色切换条。
    2. 
                
  2. 新建角色：点侧栏「+新角色」，或顶栏人形图标 →「新建角色」。
    3. 
                
  3. 懒得逐项填？用「AI 自动拆分」（旁边 ? 有说明）：把想到的一股脑写进输入框，点「AI 拆分」——它按字段拆开；没提到的会依据现有文本推断补全，填好后还能改，最后点「保存设定」。
    4. 
                
  4. 「当前设定」共 23 项：我的名称、我的性别、你对我的称呼、我的性格/外貌/背景/喜好/身体状况、你的名称、当前年龄、出生日期、性别、你的性格/外貌/背景/喜好/身体状况、你的生理期、你的说话风格、世界观、共同经历（初始）、当前关系（初始）、AI 指令。填得越细，越像。
    5. 
                
  5. “我的名称/性格/外貌/背景/喜好”留空会自动沿用「设置」里的全局「我的设定」。
    6. 
                
  6. 每个角色一套对话：第一条是主线，之后新建的算支线；在「对话设置」里可以把任意一条设为主线。
    7. 
                
  7. 当前关系 / 共同经历 / 当前场景 / 对我的认知 / 记忆压缩都是按对话分开记：主线与每条支线各一套，互不影响；都在那条对话的「对话设置」里。
    8. 
                
  8. 其中当前关系随记忆一起自动更新，当前场景每聊若干轮自动刷新；共同经历不再随聊天变（它只记对话开始之前的事，聊天之后的内容进记忆）（默认 10 轮，可在「对话设置」里改）——三样都随时能手改，改完以你写的为准。它们跟角色卡里的「共同经历（初始）/ 当前关系（初始）」不是一回事：角色卡里那份是开局设定，这三项记的是这条对话现在走到哪了。
    9. 
                
  9. 「对我的认知」随对话自动更新，也能手改或点「更新认知」重算；历史太长就「再压缩」。
    10. 
                
  10. 记忆栏：对话设置里能看到本对话的记忆（日/周/月摘要 + 精华），「再压缩」就在它下面；角色弹窗（角色名下）能看到该角色所有对话的记忆；「设置 → 角色记忆总览」一次看全部角色，不用一个个切。
    11. 
                
  11. 记忆纠偏：记忆栏下面可以写一段话让 AI 纠正记忆（如“小满其实是高中同学”）。出于对智能体的尊重，无法让你直接改角色记忆，只能用纠偏做一定量的纠正——记忆很珍贵，别滥用。
    12. 
                
  12. 「重新说」存了多个版本时，记忆压缩和认知更新都以你当前选定的那个版本为准。
    13. 
              

            

            

              
八、省 token 的记忆压缩与筛选

              
    
                
  • 自动补压：隔天再打开时，会把“今天以前”的对话按天压成日摘要，满 7 天并成周、满 30 天并成月。被摘要覆盖的旧原文不再发给模型，省 token。
    • 
                
  • 再压缩：把全部记忆极度提纯成一条精华，上下文太大时用它。
    • 
                
  • 上下文筛选：用大白话说“不要喂给角色什么”（如旁白/动作/衣着）。点「AI 筛选」→ 核对规则 → 采用并精简；也能「按规则洗一次」；可设「每 N 轮自动洗一次」。只在角色读取端裁剪，聊天记录一个字都不改。
    • 
                
  • 用量与预警：设置 →「用量统计」，看总输入/输出/总计/缓存命中率，按会话和角色分别看。上下文太大时会弹预警，去「再压缩」提纯。

十、常见问题

              
    
                
  • 请求失败/连不上：先「连接自检」，确认 Key、余额、网络。
    • 
                
  • 图片用不了 / 发图就报错：多半是「视觉模型」没配好。默认模式下图片要先转成文字才能给主模型——去「设置 → 视觉模型」配一套能看图的（见第十四节）。如果你勾了主模型区的「模型兼容」，那图片是直接发给主模型的，主模型看不了图就会报错——把那个开关取消勾选即可。
    • 
                
  • 语音/画图用不了：对应的「听觉 / 文生图 / 语音合成」模型没配齐。
    • 
                
  • 回答只有「思考」、正文是空的：这是模型偶尔的毛病 —— 它把话全写进了思考里，就"以为"自己已经答过了。分两种：①思考里带着正文（有些模型会在思考末尾用一个 response 当分界，把回答也写在思考字段里）——App 会自动把这段提出来放回正文位，不用你管；②思考里真没有正文 —— App 会自动补问一次（只补一次）。两种都救不回来时，气泡里会留一条提醒，点下面的「重新说」再来一次就行。
    • 
                
  • 思考看了一半就没了：以前在生成过程中去动设置、切角色之类，会把整条回复冲掉，现在已修；真遇到先切走再切回该对话，内容不会丢（它早就存下来了）。
    • 
                
  • 数据存在本机：卸载会清空，重要对话请自行备份。
    • 
              

            

            

              
十一、图片会“过期”（省空间）

              
    
                
  • 自己发的图片、AI 画的图片，发出去后都会自动生成一段文字描述存下来。这段描述由「视觉模型」写（主模型区勾了「模型兼容」时，就由主模型自己写）——所以视觉模型没配好，描述就是空的：默认模式下主模型收到的就只是「用户发来一张图，没有描述」。
    • 
                
  • 原图本身不再塞进聊天记录：它被搬到 App 的文件夹里，聊天里只留一个引用（打包版存原生存储，网页版才退回浏览器存储）。所以记录不会因为图越攒越多而越来越臃肿。
    • 
                
  • 原图只保留若干轮（默认 10，可在「设置 → 图片」里改）；到期后删掉原图、只留描述——聊天里原图变成「图片（原图已过期）· 描述」，之后喂给模型也只用这段文字。
    • 
                
  • 为什么这么做：几十张 base64 图片会把应用撑大、也费 token，这样能省下来。
    • 
                
  • 不想要？「设置 → 图片 → 图片转文字存储」关掉即可（原图就不再删）。
    • 
                
  • 想留住原图？到期前在图片右下角点「保存」存到手机。
    • 
                
  • 不想看图？设置 → 图片 → 打开「无图模式」，聊天和附件里的图片就不再显示（头像不受影响）。
    • 
              

            

            

              
十二、应用加密（口令门）

              
    
                
  1. 开法：设置 → 「应用加密」 → 打开开关 → 设一个口令（至少 4 位）。
    2. 
                
  2. 开了以后每次冷启动都会先锁屏，输对口令才进得去。从后台切回来不锁，不会每次都折腾你。
    3. 
                
  3. 忘了口令有两条路。一是恢复码：开启时会给你一串一次性的，只显示那一次，请抄到纸上或存进密码管理器；用过就作废，离线也能用。二是让 AI 出题：它拿你最近的聊天记录现场出几个问题考你，答对才算本人——这条要联网、且设置里配好了 API Key。
    4. 
                
  4. 防硬猜：连着输错会逐步冷却（错 4 次后锁 1 分钟，重启也还在）；AI 出题时答得太笼统会被追问，答错或者问完都答不上来会直接退出 App。
    5. 
                
  5. 口令和恢复码都只存散列，App 里没有明文。所以忘了口令又丢了恢复码，就真进不去了——请务必先把恢复码抄下来。
    6. 
                
  6. 说清楚它的边界：这是一道「口令门」，挡的是「手机被人捡到随手翻」，不等于把数据加密了。真正加密的东西在下一节。
    7. 
              

            

            

              
十三、数据与隐私

              
    
                
  • 本机加密存放的内容包括：每段对话的记忆 + 对我的认知、当前关系 / 共同经历 / 当前场景，以及整个角色卡（名称·年龄·出生日期·性格外貌背景喜好·世界观·共同经历·当前关系·AI 指令等 22 项）。做法是双层 AES（内层随机密钥，外层口令 MDLDDS），直接翻存储看不到明文。
    • 
                
  • 自动备份的快照走同一套裁剪规则：备份里也只有密文，不会把明文另存一份。
    • 
                
  • 「导出」时会让你自己设一个口令：导出文件用它加密，口令不会存进 App，导回时得输同一个——只有你能打开。忘了就永久解不开。
    • 
                
  • AI 生成的角色个人图库会跟着它所属的角色 / 会话一起导出、备份：导出时图片内联进文件（换机才带得走），会话备份只带最近 3 张以控制体积。
    • 
                
  • 说清楚边界：上面这层加密的密钥材料（设备标识 + 盐）都在这台机器上，它挡的是「拿到文件直接翻看」，挡不住有备而来、能动手提取数据的人。想再严一档只能靠「口令派生」（每次开机输口令、忘了就彻底没了），当前版本没做这个取舍。
    • 
                
  • 数据都存在本机：打包后的 App 用原生存储（没有浏览器那 5 MB 的限制）；在网页/预览里打开时会退回浏览器存储。卸载 App 会连同数据一起删，请定期导出备份。

十四、进阶：给「听觉 / 朗读 / 画图 / 视觉」配上模型

              
DeepSeek 只会「聊天」，它听、说、画、看都不行。想用语音输入、朗读、画图、看图，得另外找一家服务商。好消息是这四样都用同一套「OpenAI 兼容」标准接口，注册一家就能全解决。

              
第一步：注册一个服务商（推荐「硅基流动」：中文界面、支付宝充值、不用翻墙）

              
    
                
  1. 打开 cloud.siliconflow.cn，用手机号注册，然后完成实名认证（不实名调不了接口）。
    2. 
                
  2. 登录后左侧找「API 密钥」→「新建密钥」→ 复制那串 sk- 开头的。
    3. 
                
  3. 新用户会送十几元额度（约两千万 token）。下面推荐的模型里有几个是免费的，够你玩很久。
    4. 
              

              
第二步：先记四条铁规矩（不知道这个，填了也是白填）

              
    
                
  • 地址必须带 /v1：写 https://api.siliconflow.cn/v1。少写 /v1 会直接报 404，这是踩得最多的坑。
    • 
                
  • 「留空」会沿用主模型，但主模型没这本事：每套配置的「接口地址 / API Key / 模型」留空时会去沿用「主模型」那一套的值。可 DeepSeek 只是个文字模型，压根没有转写 / 合成 / 画图 / 看图的接口——留空等于借了个不会干这活的模型。所以这四组必须各填各的。（唯一的例外是「视觉」：主模型自己就能看图时，让视觉区留空、改去勾主模型区的「模型兼容」，反而更好。）
    • 
                
  • 填完要勾开关，还要往下滚点「保存设置」。不勾开关等于没配，不保存等于白填。
    • 
                
  • 每区都能建多套配置：听觉 / 朗读 / 画图 / 视觉各自都有「添加配置」按钮，最多 6 套，彼此独立，互不影响（主模型那 6 套也跟它们互不影响）。每一套是「名字 + 接口地址 + API Key + 模型」四项，卡片右上角标着「使用中」的那套才是当前生效的，点别的卡片上的「用这套」切过去。
    • 
              

              
第三步：分别去设置里填（每一处都是：填进那张卡片 → 点「用这套」/保证它是「使用中」→ 勾开关 → 滚到底点「保存设置」）

              
    
                
  • 听觉（语音输入） → 设置里找「听觉模型 · 语音转文字」。接口地址 https://api.siliconflow.cn/v1；API Key 填你的 sk-…；模型填 FunAudioLLM/SenseVoiceSmall（免费）。
    别填 whisper-1——那是 OpenAI 的模型名，硅基流动上没有；输入框里的灰色提示字样只是示例，不是推荐值。语言提示可填 zh。最后勾上「启用语音输入」。
    用法：点一下麦克风开始录音、再点一下结束，它会转成文字填进输入框（还得自己按发送）。
    • 
                
  • 朗读（文字转语音） → 「语音合成 · 朗读」。地址同上；模型填 FunAudioLLM/CosyVoice2-0.5B（约 0.05 元/千字）；音色要写成 FunAudioLLM/CosyVoice2-0.5B:alex 这种「模型名:音色名」的格式（这里已默认填好这一个，换别的音色时照同一格式改）。注意 alloy 是 OpenAI 的写法，在硅基流动上会报错。具体有哪些音色，看平台模型详情页。勾「启用朗读按钮」；想让它念完一条自动念下一条，再勾「回答完自动朗读」。
    用法：每条 AI 消息下面有个喇叭图标，点一下念出来。
    • 
                
  • 画图（文生图） → 「文生图」。地址同上；模型填 Kwai-Kolors/Kolors（免费）或 Tongyi-MAI/Z-Image-Turbo（约 0.1 元/张）；尺寸填 1024x1024。勾「启用画图开关」。
    用法：设置里勾完，还要在输入框下方把「画图」开关也打开（两处都开才生效），然后直接让它画。
    • 
                
  • 视觉（看图 / 图片转文字） → 「视觉模型 · 看图」。它只干一件事：把图片转成一段文字描述（不会用它来聊天）。DeepSeek 的主模型看不了图，所以你一发图、或 AI 一画图，都得靠这一区把图写成文字，主模型才「看」得到。地址同上；模型填 Qwen/Qwen2.5-VL-72B-Instruct（硅基流动）或 qwen-vl-max（阿里百炼），勾「启用独立视觉模型」。
    但如果你的主模型本身就是多模态（自己就能看图）：去主模型区把「模型兼容」勾上，本区整段留空、开关也不用开——看图会直接走主模型，这里配了也不生效。
    • 
              

              
关于主模型区那个「模型兼容」开关（很多人会配错，单独说一句）：
不勾（默认）：主模型只当纯文字模型。图片一律先过「视觉模型」写成文字再喂给它——哪怕你换的主模型其实能看图也一样，图片不会直接发过去。
勾上：主模型能看图，图片直接交给它，视觉区那套配置被无视。
一句话：不勾最安全，配错了最多是多花一次转文字的钱；勾错了则可能因为主模型看不了图而整条消息报错。不确定就别勾。

              
第四步：提前知道这些坑

              
    
                
  • 报 404：地址少了 /v1，或者末尾多带了斜杠、多写了路径。
    • 
                
  • 报 401 / 403：Key 复制不完整、没实名、或者余额为 0。
    • 
                
  • 报 400 且提到 model：模型名写错（大小写、斜杠、连字符都要一模一样）。
    • 
                
  • 报 400 且提到 voice：朗读音色格式不对，要「模型名:音色名」。
    • 
                
  • 提示「未配置语音转写 / 语音合成 / 文生图接口地址或密钥」：这一区和主模型的地址、Key 全都空着——留空会去沿用主模型，主模型也空，那就真没得用了。
    • 
                
  • 点麦克风没反应：第一次会要麦克风权限，点了「拒绝」就再也调不出来，得去系统设置里放开；网页版或老封装还可能压根不支持录音。
    • 
                
  • 点喇叭没声音：有的环境不允许自动播放；也可能是音色或模型填错。
    • 
                
  • 尺寸报错：只填平台支持的尺寸（一般是 1024x1024、768x1024 这类），别自己编。个别平台只认 image_size 这个参数名，遇到这种就换一家。
    • 
                
  • 朗读最费钱：四样里只有它按字数收费，长回答反复点喇叭会花钱，注意。
    • 
              

              
也可以用别家：只要它「兼容 OpenAI 接口」就行——阿里云百炼的兼容模式地址 https://dashscope.aliyuncs.com/compatible-mode/v1，智谱 https://open.bigmodel.cn/api/paas/v4，OpenAI 官方 https://api.openai.com/v1（但要外网和境外支付，不方便）。地址一定要带到带版本号的那一层，模型名照平台文档抄。

              
顺带一提：联网搜索源（设置里「联网搜索」那节）默认用内置的几个免费实例，不稳时可以填 tavily.com 申请的 Key（每月有免费额度），或自填一个搜索接口地址加密钥。

            

            

              
十五、6.0 新功能速览

              
6.0 加了「手机」「群聊」和一批可开关的玩法。下面按模块说，开关基本都在「设置 → 高级功能」里。

              
手机（类微信）

              
    
                
  • 怎么进：侧栏点「切换手机」进角色列表（一个角色有多条线时先选线）；或在某个会话顶栏点手机图标，直接进当前角色当前会话的手机界面。
    • 
                
  • 能干什么：发消息、转账（金额和备注随便填）、发位置（示意地图）、发图片（相机 / 相册，走视觉模型）、发语音（听觉 / 朗读）。
    • 
                
  • 长回复自动拆成几条：角色一次说得长，会像真人那样拆成好几条发出来（按行拆，单行太长再按句末切，最多 6 条）——不再闷头塞一大段。
    • 
                
  • 和主对话共用记忆：手机里聊的内容照样进「场景 / 关系 / 共同经历」三层记忆，日更也算数。
    • 
                
  • 单独算钱：手机消耗单记一类，走「手机花费预警」，不跟主对话混在一起。
    • 
              

              
伪电话：点手机里的「电话」→ 拨号、等角色「接通」→ 自动开始语音转文字。你说的话实时变成文字喂给角色，它的回复再朗读出来；通话中随时可静音（不用再按住说话）。

              
视频通话（live2D）：通话界面点「视频」，会加载 live2D 形象；没配模型、或设备不支持 WebGL，会自动退回静态头像图通话，不会白屏报错。模型在设置里配，旁边有「测试」按钮。

              
角色自己也会发动态：跟着「日更」走，一天最多 2 条，没值得发的事就空着（不会为凑数硬发）。开关在设置 → 文生图那一栏：「角色会自己发动态」默认开；再下面「动态里可以带图」默认关——它和「手机里的角色自己发图」是同一套画风与形象一致机制，但要单独开，不开就只发文字。角色的动态在手机页「动态」列表里显示他自己的头像和名字（不是我），标「公开」，也没有删除按钮。

              
发布动态（挂在手机里）：纯文字或带图发一条；可用「AI 自动筛选」——输入一条标准（如「和我一起看过电影的」），它会模糊检索相关对话，再大致总结「那天看了什么、发生了什么」供你选。

              
手机里的时间：和主对话共用同一套「故事时间」。相邻两条消息隔了 3 分钟以上（自己发的、对方发的都算）就会插一条居中的时分，像微信那样。

              
群聊：可建「手机群聊」或「普通群聊」，不建就是零消耗。多角色在同一会话里，AI 按各自性格动态决定谁发言、说几句；可从某条已有线导入同步记忆。建群时每位成员要绑一条线，群聊里还有「对彼此的认知」和「同步到各自线」——细节在第十六节。

              
世界生成（可关）：离线一段时间再上线，可让 AI 按天生成剧情，交代角色这段时间每天（早 / 午 / 晚）做了什么；能换一批、也能跳过。
                剧情一天一个框，不合意直接改，改完再「采纳」——采纳的是你框里的内容。
                采纳后不会变成谁说的话，而是在聊天流里浮出一张居中的剧情卡；点它铺满全屏看全文，左上角返回，再点开时会接着上次读到的位置。

              
每条对话单独决定要不要主动发消息：对话设置里有「本条对话允不允许角色主动找你」——跟随全局 / 允许 / 不允许。
                选「允许」后，AI 每次主动找你之前会先读「当前场景」：你俩此刻正在一块儿，它就不发这条。

                前提：这条对话要开着「时间系统」（对话设置 → 时间，也就是设过故事时间）。没有时间轴就不知道「隔了多久、现在是几点」，
                主动发来的消息会没头没尾 —— 所以没设故事时间的对话不会主动发消息。

              
故事时间（时间系统）：给角色填上出生日期（角色页里有这个选择栏）和当前年龄，系统就算出他可能处在的合法时段 ——
                例：2011-02-01 出生、写着他 12 岁，那就只能落在 2023-02-01 ~ 2024-02-01 这一年内（写 2011 那时还没出生、写 2027 那时已经 14 岁了，都会被拒绝）。
                在「对话设置 → 时间」里设一个起点（精确到秒），之后故事时间就按 1:1 跟着现实走；也可以直接勾「与现实时间同步」。
                设的时间如果不在角色的合法时段里，会提示你去改年龄或出生日期。主对话、手机、世界生成、记忆摘要读的都是这套时间；
                聊天框里还能用「（第二天）」「（到了约定时间）」临时把时间推过去。

              
状态量化（可关）：把角色的害羞 / 愤怒 / 开心等数值做成折叠框显示在气泡下方，一眼看到情绪走向。

              
自动发信息（默认关）：后台没被杀掉时，角色会按性格主动找你说话；默认关闭，开了才按设定间隔触发。
                勾上「投到手机（手机模式）」，主动消息就发进手机聊天而不是主对话；配合文生图那栏的「手机里允许角色主动分享图片」，它还会按性格顺手发张图。

              
助手总结：不会自动跑，你主动问才出——给一份关系剖析报告。

              
情绪日记：你主动写才生效；AI 会参考日记，把角色的发言往你期望的方向引导。

              
其它小改：自定义聊天背景（全局默认 + 单会话覆盖）· 酒馆角色卡导入（PNG / JSON）· 「采用格式」输入框 · 场景 / 关系的日更（默认开）· 用量新增花费估算。

            

            

              
十六、群聊：成员绑线、彼此的认知、同步到各自线

              
建群时必须给每位成员选一条线（弹窗里每个人右边那个下拉，默认是他的主线）。这条绑定不是摆设：同步到各自线靠它，删线时也靠它判断该解散哪个群。没有线的角色勾不了，整行会变淡，先给他建一条线再来。

              
对彼此的认知：群聊的「对话设置」里，一个角色一条折叠条（右边写着「2 / 3」这种已填条数）；点开是他对每一个其他成员的看法，再点一层看具体内容。点「更新认知」才会更新——AI 读最近 30 条对话整理一次，不做自动更新，也不会偷偷花 token。上面那个开关决定要不要把这份认知带进对话（默认关，关着内容也留着）。

              
为什么它不会把谁是谁搞混：每条认知在喂给模型时都写成「「小明」眼中的「小红」：…」，并且明写「这不是事实、不能互换主语」。所以它不会把「小明觉得小红话少」说成「小红觉得自己话少」。

              
同步到各自线：同一处点一下，把群聊里发生的事、共同经历、当前情境，再加上每位成员对别人的印象，分别写进该角色名下那条线的当天记忆里。写的是记忆摘要而不是一个孤立字段，所以它会跟着那条线一起参与周 / 月压缩。

              
删线会解散群：如果这条线被某个群当成成员线，删除时会弹警告、点名列出会被解散的群，确认按钮 10 秒后才可点。删掉就一起没了，先把要留的东西导出。

            

            

              
十七、检查更新与外链

              
检查更新：「设置 → 关于」里有一行「检查更新」，点一下会读一次更新清单，告诉你有没有新版本、这一版改了什么、下载地址在哪。另外启动时自动查一次，一天只查一次，发现新版本才弹窗，不打扰。

              
装新版本前先导出备份：只有签名一致的安装包才能直接覆盖安装；签名变了就装不上，只能卸载重装，而卸载会把本机数据一起删掉。所以更新提示里专门写了这一句，别忽略。

              
「跳过这个版本」：更新弹窗里点「取消」= 这个版本先不提醒了（自动检查不再弹它），但手动点「检查更新」仍会提示。

              
外链为什么不会在应用里打开：指南里的 DeepSeek 开放平台、硅基流动、Tavily 这些链接，点了是交给系统浏览器打开，不会把应用界面顶掉。万一封装工具没提供「打开链接」的原生接口，会退回复制链接并提示你粘到浏览器——无论如何都不会在应用内跳走。

            

            

              
十八、模型能力与可上传的文件类型

              
为什么要限制上传类型：模型读不了图的时候，你传进去也只会白等一轮，再拿到一句「不支持图片」。先把文件选择器卡住，省的是这一轮时间，不是不让你用。

              
能力是怎么判出来的（设置 → 主模型 → 检测主模型能力），顺序是：内置表（常见模型直接命中，不发请求、不花钱）→ 问模型自己（用你填的 key 调一次，让它只回一段 JSON）→ 都没问出来，就先不限制，结果行会如实写「未确认」。

              
「没确认」不等于「不支持」：这一版改了判断口径——问不出结论时上传类型原样放开，不会因为你打开过一次设置就把图片入口关掉。判定为纯文本才真的收紧，而且只收紧主聊天那个文件选择器。

              
配了独立视觉模型就不受这个限制：主模型看不了图、但你在「设置 → 视觉」里配了能看图的模型时，图片照样能传——发送前先用视觉模型转成文字描述，再交给主模型。上传类型跟着这条链路一起放开。

              
手动勾的那四个优先级最高（看图 / 听音 / 朗读 / 画图）：勾过之后不再自动重测，也不会被后台结果冲掉。模型能力变得很快（例如 DeepSeek 从 V4.1 Flash 起就能看图了），看到表里的旧结论又不服气，直接勾一下，别跟内置表较劲。

              
这一轮检测花了多少：走内置表不花钱；走「问模型自己」是一次真实调用，记在用量统计的「模型能力检测」一栏。同一个模型名问过一次没结论，不会每次进设置都再问。

            

            

              
十九、联网搜索（含 DeepSeek 自带搜索）

              
搜索源在「设置 → 搜索」里选：Tavily、自定义接口、DeepSeek，或者 auto。auto 的规则是：主模型是 DeepSeek 时先走它自己的搜索（质量稳、带长摘要），失败或没结果再退到免费源——你永远拿得到东西。

              
DeepSeek 搜索有两条通道：先打 /v1/tools/search（纯检索，便宜）；这条不通或返回空，会自动退到官方文档明确支持的 /anthropic/v1/messages + web_search_20250305 服务端工具。

              
官方通道只给答案、没给来源块时：结果区会出现一条「DeepSeek 联网答复」，它是不可点的——那不是链接坏了，是这次确实没取到网址，只取到了正文。以前这种结果会被过滤掉，看着像「搜了个寂寞」。

              
费用差别要心里有数：纯检索只算检索的钱；带搜索的那次 Messages 调用等于完整跑了一轮模型（官方没有独立检索端点）。所以是「先便宜后贵」，不是每次都贵。

              
注意 chat/completions 不支持搜索：往里塞 web_search_options 或 enable_search 不会报错，但也不会检索（返回里没有引用、用量也不变）。要用官方搜索只能用 Responses 或 Anthropic 兼容 Messages 那两个接口。

            

            

              
二十、表情包：内置 48 个，也能加自己的

              
入口在手机聊天：输入栏右边那个笑脸。点开是两栏——「常规表情包」是内置的 48 个，「自添加表情包」是你自己传的图。

              
点一下插进输入框：内置那栏点任意一个，字符会插到手机输入框的光标处，发出去显示成图（不再是系统 emoji）。点面板外面或再点一次笑脸就收起。

              
加自己的表情：自添加那栏右上角「+」→ 选图（可多选）→ 面板里默认全选，点掉不要的 → 上方选范围 → 「导入」。图会压到最大边 192、保持原比例、保留透明，长条表情不会被切。

              
三档使用范围：都能用 / TA 用 / 自己用。长按任意一张可以直接改它属于哪档（改之前先切到对应页签，切页签会自动退出改范围态，避免改错对象）。「自己用」那档不会出现在给模型的清单里。

              
模型也会发表情：系统提示词里会把它能用的表情名字列给模型，它想逗你、害羞、无语时可以在单独一行写 [表情:名字]，渲染出来就是那张图。它看不见图，认的是名字和意思——所以表情的名字取得说得通很重要，配了视觉模型时程序会自动看图写一个。

              
花费记在哪：自动命名会调一次视觉模型，记在用量统计的「表情包命名」一栏。没配视觉模型就不调，直接用「表情1、表情2」这样的默认名。

            

            

              
二十一、TA 的思考：角色自己记的日记

              
只在「时间系统开着、且时间没被冻结」时工作。没设故事时间的线不会记录——没有时间轴，就没有「哪一天」这回事。群聊也不记：思考是按「一个人」的性格写的，群里没有唯一的「他」。

              
什么时候记：记忆更新之后、世界生成时、以及角色在后台主动找过你之后。其中世界生成优先级最高：某一天已经由剧情带出想法，记忆更新就不会给同一天再写一遍。

              
记什么：按他的性格想事情，不是通用感想。学者会琢磨学习 / 研究上的事，爱哲思的人会想抽象的问题，敏感的人会反刍一句话的语气；允许跳跃、自问自答、无厘头。一天一条，同一天同一来源只记一次。

              
先只存不读：平时这些想法不进对话上下文，既不影响角色说话，也不额外烧 token。

              
七天一循环：每过七个故事日自动压缩一次——特别碎的只留结论，带过程的只留关键。压完让角色读一次，之后七天不再读；那一段会继续留在上下文里（相当于「他还记得自己前阵子在想什么」）。

              
在哪看：对话设置里「TA 的思考」那一栏，按故事日期倒序列出，压缩过的那段单独置顶。只能读不能改。

              
想让它现在就读：点「读取」，会立刻压缩一次并注入上下文。点「压缩」只压不读。

              
纠偏：底下那个输入框写「哪里想得不对」，AI 会核对。但它只改与角色设定冲突、或明显离谱的推论与观点——语气、偏好、情绪本来就可以反复，不算错，不会因为「和前面不一样」就改。

              
读了以后会不会说：按性格来。有的会一股脑说出来，有的只自然流露一点，有的干脆不提。提示词里写明「提不提由你的性格决定」，不会强行让他汇报。

              
花费：记录、压缩、纠偏都是真实的模型调用，记在用量统计的「TA 的思考」一栏。

            

            

              
二十二、6.2.4 这一版改了什么

              
出生日期能填到公元元年了：日期滚轮只到 1900 年，所以「你的出生日期」下面多了一个年份输入框——填 1~9999 覆盖滚轮选出来的年；填 0 就是「0 年 0 月 0 日」＝无限年龄：年龄栏会被禁用，但时间系统照常能开。

              
年龄是硬规则，但会长：设定时间那一刻，合法时段就是「出生日期 + 填写的年龄」定出的那一年（例：2012-02-10 出生、年龄 12 → 只能落在 2024-02-10 ~ 2025-02-10）；缺出生日期或缺年龄，不准开时间系统。开了之后年龄随故事时间增长（满周岁 +1），合法时段跟着往后走 —— 这两件事本来就是一套，不冲突。唯一例外是无限年龄（出生年份填 0），那时不做限制。

              
本线年龄：对话设置里多了一栏「本线年龄」，留空就用角色卡的；只影响这条线，不写回角色卡。填了就以它为准。

              
混搭模式：时间设置下面那个勾选框。勾上之后离开应用就冻结时间，回来发第一条消息时解冻——离线那段时间不推进，也不用每次手动调。只对这一条线生效。

              
没开时间系统时的「（第二天）」：记忆里不再据此编造具体日期，而是改写成「次日」「隔了几天」这种叙述，日期用当天。气泡里你写的原话不变。

              
回溯改成开支线了：在任意一条消息上点「回溯到此刻」，不再丢内容，而是新建一条支线（名字是原名 + 数字），只带这条及之前的主聊天消息和手机消息；记忆、认知、关系、共同经历、场景会按「这条之前 20 条」重新生成（后面 20 条只用来判断哪些事不能写进去），花费记在「回溯重建」。原线原样保留；想让支线变主线，去对话设置点「设为主线」。

              
删除会连带删主聊天：手机里删一条（或批量删），主聊天里绑定的那条也会一起删掉，删前会问一句。

              
手机长按对齐主聊天：AI 消息长按直接进多选（在里面选删除 / 转发 / 合并转发）；你的消息长按在气泡旁边浮出菜单——修改 / 朗读 / 搜索 / 复制 / 撤回 / 多选 / 删除本条。撤回不问，删除要问一句。

              
手机能转发了：长按任意消息 →「多选（转发）」→ 勾几条 → 点「转发」或「合并转发」→ 选对象（可多选，联系人和群都能选）。合并转发会生成一张「与「某人」的聊天记录」卡片，点开是列表；交给 AI 时每条都写成「名字：内容」，它会当成一段转发记录来读，不会当成此刻说的话。

              
群聊能 @ 了：群聊输入框左边多一个「@」按钮，选谁就插一个「@名字」。@ 的意思是提醒某个人看，不是点名让他先发言——被提醒的人通常会回应，但谁接话仍按各自性格来，其他人非必要不插话。

              
撤回更彻底了：撤回自己那条时，如果对方已经回了，那条回复也一起撤回；如果还在生成，直接中断请求。内容界面上看不到，但 AI 知道「你撤回了什么」，会据此揣摩。

              
思考对象：对话设置里能多选「TA 的思考」要想谁——自己、你、或者群里的某几个人。默认只想着自己。

              
搜索分成两边了：搜索面板顶部多了「主聊天 / 手机」两选，下面可以再限定范围（全部 / 某个角色 / 某条线 / 某个群）。时间和关键词筛选照旧；点手机的结果会直接切到那条线并打开手机。

            

            

              
二十三、6.2.5 ～ 6.2.7 这一版改了什么

              
手机群也能建了：手机页「+」→「建群聊」，和现实群同一套规则——每个成员都要选一条线（下拉里前面带 ● 的是这条线已经有手机消息），也能导入某条线的记忆。两份绑定互不影响：同一个角色可以在现实群绑 A 线、在手机群绑 B 线。

              
群和各自的线记忆互通（两个方向都有）：读 —— 群里每位成员按自己绑定的线，带上关系 / 共同经历 / 认知 / 最近的记忆摘要 / 最近刚说过的原话 / 他自己写下的思绪 / 图库里的样子，并且标明「这些只是他自己知道的事，不是全群共有」。写 —— 每轮结束把群里发生的事写回各自那条线，同一天同一个群按标记替换，不会越堆越多。手机消息和主聊天本来就挂在同一条线上，所以写回去以后两个界面立刻都能看到。

              
群也有记忆压缩了：现实群和手机群都参与每日压缩，摘要里会带上「谁说的」，否则压完分不清哪句是谁。

              
表情改成两段式（只在手机里）：先让模型把话写完、先不发，再带着这段正文和他的性格去挑一个表情，最后一起发出来，表情是单独一条。能用哪些按上传时设的「可用范围」算，上限 50 个，第一段的提示词里不出现表情清单。想发在情绪落点上就发，没有落点就不发。代价是每条回复多一次很小的请求。顺带一句：主聊天和现实群都不再出现表情，那里本来就不该有。

              
角色能自己查资料了：设置 → 高级功能 →「让角色按需读取这条线自己的资料」（默认开）。开了以后角色在需要时可以自己查两件事 —— 读这条线的记忆摘要 / 思绪 / 图库 / 认知（line_read），或者在最近 100 条里按关键词找原话（line_search）。只能读当前这一条线，读不到别人的；也纯只读，不会改你的数据。模型不支持工具调用时会自动退回普通回答，不会发不出去。

              
视频 / 音乐 / 文档只跟听澜有关：这三样只在和听澜（助手）对话时才会出现，角色扮演里不再冒出 [[视频]] 这类标记。

              
存文件更稳了：图片、文档、备份现在共用同一套目录规则（外部文件目录 → 内部文件目录）。图片保存成功会直接把路径告诉你；文档导出会逐个目录试，写不进去才是真失败，不会再假报「已保存」。

              
用量统计：「文档评析」现在有单独一类；群记忆压缩的花费归在「记忆压缩 / 认知」里，不再显示成 mem。

              
6.2.7 修了四处账目与显示的老毛病：搜索超时以前会被当成「你点了停止」（主对话里还会静默停在半截、不报错），现在超时如实说超时；视频 / 音乐的花费以前不显示在「按类型」里，合计和明细对不上，现在单列两类；从备份恢复数据后，第一次保存会把那条线的记忆洗空，现在恢复出来会先把记忆解回来；编辑过的消息以前旁白不再变灰、表情会变回 [[s:xxx]] 这种代码，编辑开场白还会把卡片塌成纯文字，都已修好。

              
当前版本 7.1.2。

            

            

              
二十四、手机里怎么转发、怎么 @ 人

              
多选转发：长按任意一条消息 → 菜单第一项「多选（转发 / 合并转发）」→ 勾几条 → 底部操作条选「转发」或「合并转发」。转发对象可以一次选好几个：每个角色一行（消息进他的主线），每个群一行。

              
合并转发：把勾中的几条打成一个「与「某人」的聊天记录」卡片，点开是只读列表。交给模型时每条写成「名字：内容」，并注明这是转发记录、不是此刻说的话，免得它当成刚发生的事。

              
@ 提醒：群聊输入框左边的「@」按钮，选成员插入 @名字。它的意思是提醒这个人看，不是点名让他先发言 —— 被提醒的人通常会回应，但谁接话仍按各自性格。

              
撤回和删除不是一回事：「撤回」会把这条、以及紧跟其后的这一轮 AI 回复（三分钟内连续的几条）一起变成「已撤回」，主聊天里对应的线下描写也一起撤；如果它还在生成，撤开会直接中断。「删除」只删手机里这条，但会连带删主聊天里绑定的那条线下描写 —— 删之前会问一次。

            

            

              
二十五、事件簿：所有线摊在一张表上看

              
入口：侧栏最下面那个「事件簿」。打开后按「世界观 → 世界线 → 日期」三层摊开，点标题逐层展开 —— 能一次看到每条线在哪一天发生过什么，不用一个个角色切过去翻。

              
标着「转述」的条目是听说的，不是他亲眼见过的：这类事来自别的线提到他（见「二十七、别人那儿的事」），写进事件簿时单独标出来，免得日后自己搞混「他到底知不知道这事」。

              
纯本地聚合，不花 token：事件簿只是把已经存下来的消息、事件、世界生成结果按时间归拢，不调用模型、不计费。「按天归档」也是本地做的。

              
可以关掉：设置 → 高级功能 → 事件簿。关掉之后不再记新事件，侧栏那个入口也会消失（已经记下的不会被删）。

            

            

              
二十六、性格变化：让他慢慢变成另一个人

              
前提：这条线得开着时间系统 —— 性格变化按「故事周」走，没有时间轴推不动。

              
怎么用：对话设置 → 性格变化 → 写一句「想变成什么样」（例：不再一味迁就，会开始拒绝），点「规划路线」。AI 会排一张 4~6 周的周表，之后每过一故事周自动往前走一格；随时能暂停、也能「恢复原样」一键回退。规划那一步是一次真实的模型调用，花费单独记在「性格变化（路线规划）」里。

              
不改角色卡：它只在拼提示词时往上叠一层当前阶段，角色卡里你写的那份设定一个字都不动。所以同一张卡开两条线，可以走出两种性格；关掉就回到原样。

            

            

              
二十七、别人那儿的事（跨线传播）

              
是什么：别的世界线里提到过他的事（「听说他最近在准备考试」），会被收集成「听说」。他要不要主动跟你提，取决于他对那个人的信任度 —— 信任 ≥45 才会主动提，不够就含糊过去或者干脆不提。

              
什么时候跑：离线剧情生成时会自动转述一次；想马上补，去事件簿那一段的「同步一次」手动跑。纯本地判定，不调用模型、不花钱。

              
为什么有时啥也没有：要么别的线最近没提到过他，要么信任还不够 —— 界面上会如实说一句，不会假装转述了。

            

            

              
二十八、世界观库

              
在哪：设置 → 我的人设 → 世界观。内置 10 套（现代 / 古代中国 / 古代西方 / 修仙 / 西幻 / 现代修仙 / 架空古代…），每套都压在 100 字以内 —— 够模型建立框架，又不吃掉太多上下文预算。

              
内置的只读：想改先点「复制当前」生成一份自己的再改，避免误删找不回来。自己建的最多 50 套，可以搜索、可以删。

              
角色卡那栏留空 = 用选中的这套：角色「当前设定」里的「世界观」如果空着，就用这里选中的那套；自己填了就以自己填的为准。时间域关联（两条线共用冻结）要靠 AI 甄别世界观是否一致，所以那两条线的世界观得能对上。

新增：事件簿（二十五）、性格变化（二十六）、跨线传播（二十七）、关系网（角色之间的信任 / 好感 / 熟悉 / 依赖 + 关系标签）。

欢迎来到 Sekulum，亲爱的创世主

          
从这里开始，你是这个世界的造物者 ——
定角色、铺时间、看他们自己往下走。

        

        

          
你能造什么

          

        

        

          
第一步：拿到钥匙

          
1. 去 DeepSeek 开放平台（platform.deepseek.com）注册并创建一个 API Key。
2. 打开「设置」→「主模型」→ 把 Key 填进「配置一」→ 滚到底点「保存设置」。
3. 回到对话直接开聊；想角色扮演就打开「启用角色扮演模式」。

          
· 也可以用别的平台（兼容 OpenAI 接口的都行），但大多比 DeepSeek 贵、地址要自己去官方文档搜。
· 聊天页右上角的模型按钮能随时切主模型；听觉 / 朗读 / 画图 / 视觉想用的话，在设置里各配一套（见「使用指南 · 十四」）。
· 主模型区那个「模型兼容」开关默认别勾——它表示「主模型自己看得懂图」，DeepSeek 看不了，勾了发图会报错。想发图就配「视觉模型」。

        

        

          
这个世界只在你手里

          
· 聊天记录、角色卡、设置都存在本机，不上传第三方。
· 记忆、角色卡、场景 / 关系 / 经历在本机加密存放；导出的文件由你自设口令加密，口令不存进 App。
· 可选开「应用加密」：每次冷启动先锁屏；忘了口令可用一次性恢复码或让 AI 出题考你找回。
· 实话一句：本机加密挡的是「捡到手机随手翻」，不是对抗专业的数据提取。

        

        

          
接下来三件事

          
1. 打开设置 → 主模型，把 API Key 填进「配置一」，滚到底点保存设置；旁边的连接自检显示「成功」就成了。
2. 回首页点左上角菜单 → 新对话，直接打字就能聊。想让她有设定，就打开启用角色扮演模式，或者从预设角色里挑一个开始。
3. 给角色填上出生日期和年龄，故事时间就开始走了 —— 不填也能聊，只是没有时间轴。

          
剩下的慢慢来：右上角「+」里有拍照、文件、画图、视频和音乐；侧栏三个图标分别是听澜 / 现实角色 / 手机；所有开关都在设置里。哪天迷路了，回来看这份引导（设置 → 关于 → 重看首次引导）。

        

        

          
一些顺手的

          
· 快捷回复：输入框左边（加号右边）那个无边框按钮，AI 站在你的立场给几条「这时可以怎么回」，可以换批、点铅笔填进输入框；继续说在角色最后一条消息的操作栏里。
· 故事时间：给角色填上出生日期和年龄，就能锁定他的合法时段；顶栏「对话设置」按钮上直接显示故事里的时:分。
· 剧情卡：世界生成采纳后浮一张居中的卡，点开铺满全屏看全文。
· 记忆压缩 / 再压缩 / 上下文筛选：让长对话不越聊越贵。
· 图片（自己发的 / AI 画的）会在若干轮后删原图、只留「视觉模型」写的文字描述，省空间也省 token。
· 对话很长时只先渲染最近 20 条、往上滑再加载，不会越拉越卡。
· 对话和角色都能置顶、排序（长按即可）。
· 记忆栏能看记忆，记错了可用「记忆纠偏」让 AI 纠正（勿滥用）。
· 消息「重新说」存了多版本时，记忆与认知以你当前选定的版本为准。
· 用量统计与预警：随时看花了多少。
· 导入导出与自动备份：换机、防丢。
· 群聊：建群时每位成员绑一条线；「对话设置」里能看对彼此的认知（一人一条折叠条，可开关、手动更新），也能一键同步到各自线。
· 表情包：手机输入栏那个笑脸，内置 48 个；也能自己加图，按「都能用 / TA 用 / 自己用」分范围，模型会挑着发。
· 模型能力检测：设置 → 主模型 → 检测主模型能力，按结论决定能传哪些文件；配了独立视觉模型就不受这个限制。
· 手机群：手机页「+」→「建群聊」，和现实群一样每位成员绑一条线，两份绑定互不影响；群里聊的事每轮自动写回各自那条线。
· 表情是两段式：先把话说完，再带着这段话和他的性格单独挑一个表情，作为单独一条发出来（只在手机里，最多 50 个，按上传时设的「可用范围」）。
· 角色能自己查资料：设置 → 高级功能 →「让角色按需读取这条线自己的资料」（默认开）。它能自己翻记忆摘要、找旧原话，只读当前这条线，不改任何数据。
· 检查更新：设置 → 关于，启动时每天自动查一次，有新版本才提示；装之前记得先导出备份。

          
· 年龄会长：故事时间开着时，角色满周岁就 +1，合法时段跟着后移，提示词里给他的年龄也跟着变（不是卡片上那个静态值）。
· TA 的思考：时间开着时，角色按故事日期自己记内心，平时只存不读，每七个故事日压缩一次并读一次；对话设置里能查看、能手动读、能纠偏。
· 回溯不丢内容：任意一条消息上点「回溯到此刻」会新建一条支线，原线原样保留；记忆按回溯点前 20 条重建。
· 手机页只列手机群：现实群在侧栏「现实扮演角色」里，不从手机露头（两边消息存的地方不同，混着看会串）。

          
更多在「设置 → 关于 → 使用指南」。创世主，去造你的世界吧。
